# What to commit

Track project text/code and the two approved image trees only:

- **Commit:** non-image files (docs, scripts, skills, site code, etc.)
- **Commit:** `vtarot/` (framed gallery cards + site)
- **Commit:** `illustrations-rectified/` (canonical 7:12 masters)
- **Do not commit:** `tmp/` (drafts and intermediates)
- **Do not commit:** `rejected/` (superseded or rejected versions)
- **Do not commit:** other image-heavy trees (`illustrations-raw/`, `illustrations-cleaned/`, `reference/`, `rider-waite/`, etc.) unless a specific non-image file there is needed

`.gitignore` encodes this policy.
